# حسابات مزرعتي — My Farm Accounts

تطبيق محاسبي وإداري لمزارع النخيل، مبني بـ Flutter ليعمل على Android والويب.

## MVP الحالي
- لوحة تحكم متجاوبة.
- الإيرادات والمصروفات مع CRUD.
- البحث والتصفية.
- دعم العربية والإنجليزية وRTL/LTR.
- تخزين محلي للحركات داخل الجهاز.
- بنية جاهزة لإضافة Supabase والحسابات السحابية.
- Workflow لبناء APK Release تلقائيًا.

## البناء محليًا
```bash
flutter pub get
flutter run
flutter build apk --release
```
